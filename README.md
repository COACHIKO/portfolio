# Muhammed Mahmoud | Senior Flutter Developer Portfolio

Personal portfolio and engineering showcase for **Muhammed Mahmoud**, Senior Flutter Developer specializing in enterprise-grade Mobile (iOS & Android) and Desktop (Windows & macOS) applications, VoIP systems, and Clean Architecture.

---

## 🚀 Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion & Lucide Icons
- **Typography:** IBM Plex Sans Arabic & Readex Pro
- **Deployment:** GitHub Pages / Vercel / Netlify

---

## 🛠️ Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run dev server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

---

## 🌐 Deploy to GitHub Pages

This repository is pre-configured with a GitHub Actions workflow (`.github/workflows/deploy.yml`):

1. Push your repository to GitHub.
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Every commit pushed to `main` (or `master`) will automatically build and deploy your site live.
